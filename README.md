# becareful-media-images

Images des carrousels BeCareful Media, hébergées ici pour que Metricool puisse les récupérer au moment de la programmation sur Instagram.

Le projet lui-même (contenu, sources, outil) est dans un dépôt privé séparé.

## Règles

- **Ce dépôt est public.** Tout ce qui s'y trouve est visible par n'importe qui.
- **Uniquement des images approuvées.** Une image n'est ajoutée qu'après l'approbation explicite de la version exacte du carrousel, juste avant sa programmation.
- **Rien ne s'efface vraiment.** Une image supprimée reste dans l'historique du dépôt. Les images ne sont donc pas supprimées après publication : Metricool ou Instagram peuvent encore en avoir besoin.

## Organisation

Un dossier par carrousel, avec le même nom que dans le projet :

```
AAAA-MM-JJ_sujet/
  01.jpg
  02.jpg
  …
```

Lien public d'une image, à donner à Metricool :

```
https://raw.githubusercontent.com/cedrictranier-prog/becareful-media-images/main/AAAA-MM-JJ_sujet/01.jpg
```

GitHub met ces liens en cache environ cinq minutes : une image qui vient d'être ajoutée peut mettre quelques minutes à apparaître.
